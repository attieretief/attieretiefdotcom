# /public/img — source image drop folder

This is where source images live (DRC register photos, death notice scans, family
documents). They are referenced by filename from the `sources:` array in each
person's or line's content file.

## To capture from FamilySearch (in your signed-in browser session)

For each entry in `assets/IMAGE_CAPTURE_WORKLIST.md`:

1. Open the source URL in your browser.
2. In the image viewer, screenshot the relevant entry.
3. Save to this folder with the filename that the worklist + person file expects.
